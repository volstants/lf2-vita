# claude_typing_nome

Controle dirigido da edicao de nome na tela de controles (callsite 0x428b2e de 4246b0, que chama 0x422f60). Cobre letras, digitos, as dez teclas do teclado numerico sem Num Lock, Backspace (inclusive com o nome vazio), o limite de 10 caracteres e Enter. Nao confirma a tela: nenhum arquivo e gravado.
